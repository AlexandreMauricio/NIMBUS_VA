Current context

Everything NIMBUS knows right now, one box per source. The sources are asked side by side, each with a 30-second limit: if one fails, its last good answer is shown marked stale and the others are unaffected. Open a box to see how that source works and what it returned.

Attention

Every 30 seconds NIMBUS looks at your calendar, tasks, email, weather, stocks, activity and routine suggestions, and scores each thing: 0.40 × urgency + 0.35 × importance + 0.25 × relevance, less when you're busy with something that can wait. Urgent and high items can pop up, one at a time; normal ones go to the Home feed; low ones only appear here. The same thing is never shown twice unless it becomes more pressing. Attention never runs anything.

Routines

New routine

Skip if already active

Don't suggest again while this routine's own configured playlist/timer already appear to be running — e.g. you briefly opened the site by accident, dismissed it, then actually started studying yourself; NIMBUS won't offer it again once it can see you're already doing it.

Only once per session

Suggest at most once per thing that triggered it — one application run, one page, one folder. Returning to an application that is still open won't suggest again; closing and reopening it starts a new session. Without this, only the cooldown limits repeats.

Enabled

A disabled routine is kept but never triggers. The same switch appears on the routine list.

Run automatically, no confirmation

Skip the "would you like me to?" popup entirely and just run this routine's actions the moment it triggers. Only use this for actions you're comfortable happening without asking — e.g. opening a companion website when a game launches. Cooldown still applies.

Calendar

The ICS address is treated as a credential — most calendar apps (Google Calendar, Outlook, iCloud) can generate a private "secret address in iCal format" for a calendar under their sharing settings. It's stored locally and never logged.

Email

The password is a credential — it's never sent back to this window once saved (the field always starts empty), never logged, and never leaves this device. NIMBUS only reads message metadata and short previews — it never sends, replies to, deletes, or modifies anything in your inbox.

Tasks

The API token is a credential — it's never sent back to this window once saved (the field always starts empty), never logged, and never leaves this device. NIMBUS only reads active tasks and their due dates — it never creates, completes, deletes, or otherwise modifies anything in your task list.

Spotify
Connection Not connected

NIMBUS connects to your own Spotify account via Spotify's standard sign-in — it never sees or stores your Spotify password. The connection token is encrypted using this computer's secure storage and never sent to this window.
